# 回访小助手第一版

目标：供特配奶粉销售在 iPhone 管理客户、记录咨询与回访、安排本地提醒、搜索问答和复制回访话术。用户通过自行签名安装 IPA。

技术：SwiftUI，iOS 16 及以上；本机 JSON 持久化；UserNotifications 本地通知。无服务器、无账号、无远程模型。问答搜索按标准问题、相似问法、产品标签及答案排序，中文相邻双字片段用于关联搜索。所有结果来自已录入条目。

资料：手动新增、修改、删除；CSV UTF-8 导入，七列为类型、问题、相似问法、回答、产品、标签、来源。导入先校验整份文件，再预览确认；按类型、问题、产品去重，保留已有内容。Word、PDF、XLSX 需先整理为 CSV，不承诺自动提取或生成医学答案。

客户：称呼、电话或微信、产品、关注问题、状态、创建时间、下次回访时间、回访记录。记录回访时安排下次回访或关闭提醒。首页展示今日及逾期、客户数、已完成回访记录数、成交客户数和按产品字段统计的客户数。

提醒：用户主动授权；最近 59 项未来回访安排通知；逾期客户合并为次日上午一条提醒。每次保存与返回前台重新安排。锁屏文案不显示客户姓名、症状或联系方式。打开应用补充后续提醒；本地通知不提供无限离线排期保证。

数据：写入原子更新并启用文件保护；写入失败不更新内存；读取错误保护原始文件并要求恢复；导出完整 JSON 备份；恢复校验版本及数据编号，确认后整体替换。

验证：CSV 引号、逗号、BOM、CRLF、多行内容、错误输入、搜索排序、无匹配、指纹去重与完整备份往返测试。Mac 执行模拟器测试，真机检查通知授权、杀进程后提醒、编辑/删除后取消旧提醒、文件导入/导出及恢复。

构建条件：Windows 环境可编写源码，IPA 需 macOS + Xcode 编译，脚本生成未签名 IPA，随后由用户签名安装。
